## 01 / About

**BlackForge** is an IT and digital agency working with clients worldwide. This repository is our public-facing website: the place we send prospective clients so they can see what we do, how we work, and who is behind it.

The goal is simple: look established, load fast, and build trust.

## 03 / The website

| Page | Purpose |
| :--- | :------ |
| **Home** | Hero, services, selected work, process, reviews |
| **Services** | Full breakdown of every service |
| **Projects** | Case studies with challenge, approach and result |
| **Reviews** | Client testimonials |
| **Team** | The people, with editable skill profiles |
| **How We Work** | Our process from discovery to support |
| **Blog** | Articles and insights |
| **Contact** | One-click email and FAQ |

### Design principles

- **Editorial and refined.** Large serif headlines, generous whitespace, hairline borders.
- **One restrained accent** on a near-black and warm off-white base.
- **Light and dark mode**, both designed, not inverted.
- **Calm motion.** Scroll reveals that respect `prefers-reduced-motion`.
- **Data-driven.** Services, projects, reviews, team and blog posts live in data files.

## 04 / Getting started

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# production build
npm run build
npm start
```

Open [http://localhost:3000](http://localhost:3000).

### Editing content

| To change | Edit |
| :-------- | :--- |
| Site name, nav, contact email | `data/site.ts` |
| Services, projects, reviews, team | `data/` |
| Blog posts | `content/blog/*.json` |
| Colors and fonts | design tokens in the global stylesheet |
| Logo | `components/layout/Logo` |
